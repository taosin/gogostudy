# 发现手册与生活小挑战

## 两轮讨论的结论

第一轮检查知识世界、五科课堂与探索背包后，确认当前缺口是孩子自己的表达：网站能保存到访、收藏和理解题结果，但“说说我的发现”“讲给家人听”还没有可以留下原话、修改和回看的位置。

第二轮将范围收敛为一个完整过程：**观察或动手 → 用自己的话表达 → 回看想法 → 回到原处再试**。本轮实现发现手册、六个生活小挑战及返回原地点的链接。每个目的地保留一张当前想法卡，不增加积分、打卡、自动批改或推荐。孩子可以先口头表达，想记时再写；提示只帮助开头，不替孩子填入答案。

## 从哪里进入

- 世界首页：每个地点的互动场景下方有生活挑战和“留下我的想法”。星空观测站的这组入口对应昼夜实验。
- 五科课堂：当前课程下方可以留下想法，80 节课程分别绑定自己的目的地。生活挑战只出现在明确对应的课程中。
- 宇宙专题：随当前观察范围、关系节点或实验切换记录地点；昼夜实验另有生活挑战。
- 探索背包：显示最近两张想法卡及未写完的草稿数量，进入 `/notebook` 查看完整手册。背包收起时也保留手册入口。

挑战和录入区域默认收起。“留下我的发现”展开对应的录入区域。挑战提供主动朗读，展开不会自动播放；收起或切换挑战后停止朗读。朗读沿用设备声线，文字步骤始终可用。

## 六个生活小挑战

每个挑战约 2–5 分钟，包含常见物品、三步观察或操作、表达句首和一个知识联系。活动不写入完成状态。

| 地点 | 小挑战 | 记录与返回位置 | 还可以连到什么 |
| --- | --- | --- | --- |
| 数字工坊 | 同一组积木换摆法，再数一次 | `math:count` | 语文“把观察到的样子说具体”：让别人想象看到的摆法 |
| 故事森林 | 复述一个两步请求，再互换角色 | `chinese:chinese-listen` | 地理“说位置，先说在谁旁边”：把物品位置讲清楚 |
| 时光博物馆 | 用三张纸片给今天的小事排先后 | `history:history-before-after` | 语文“先发生什么，再发生什么”：从时间词找顺序 |
| 大地山谷 | 约定相同朝向，描述桌上笔盒的位置 | `geography:geography-relative` | 语文“听清一句话里的小任务”：复述并确认听懂的位置 |
| 英语港湾 | 用玩偶或家人演见面与告别 | `english:english-greetings` | 语文“听清一句话里的小任务”：听清情景，再回应 |
| 星空观测站 | 固定灯光，转动球，观察同一个小点的明暗 | `universe:lab:day-night` | 地理“从脚下的地方，认识地球”：认识模型能帮助观察什么 |

昼夜活动请家人拿稳普通手电筒，光只照球；没有材料时可直接使用网页小地球。挑战卡在首页提供“回到相关课堂”，在课堂中提供另一处知识联系。课程放置按完整目的地精确匹配，不会在同科其他课程误放挑战。

## 记录、修改与返回

1. 展开“留下我的想法”，确认当前地点与课程标题。
2. 选择“我的发现”“还想问”或“想再试”，用自己的话写一句，最多 300 字。全空白不能保存。
3. 点击“收进发现手册”；已有卡片时显示“更新我的想法”，保存前说明会更新当前卡片。
4. 在 `/notebook` 按地点或想法种类筛选，继续草稿、修改卡片，或点击“回到这里继续试”。返回链接指向原课程或宇宙视图；记录携带有效的小旅行信息时，也保留路线入口。
5. 删除卡片前需要确认。放下草稿也需要确认，已保存的卡片不受影响。

卡片按最近更新时间排列，保留首次记录日期和最后修改日期。保存后可以继续补充，不保存历史版本的正文。

## 数据与学习边界

- 卡片按目的地分别保存在当前浏览器的 `localStorage`，每个目的地一张。不同地点的更新不会整本覆盖其他记录。
- 输入中的草稿保存在当前标签页的 `sessionStorage`，支持同一标签页刷新及站内往返后继续；未点击保存的草稿不会成为正式卡片。
- 草稿带着开始编辑时的版本号。保存或删除前再次读取当前卡片；发现别处已修改时保留草稿，要求先回看新内容并明确确认，再更新。这里不提供多人实时协作。
- 删除会清除已保存正文，只留下删除标记和版本计数，防止重建卡片后复用旧版本号。另存的未完成草稿仍保留，界面会说明，也可单独放下草稿。
- 保存失败时显示失败状态并尽量保留本页草稿，不宣称已经保存。损坏或未知版本的数据不会被新输入静默覆盖；其他有效记录仍可使用。
- 地点、类别、长度、日期和路线均有校验；正文按纯文本显示。功能不要求姓名、联系方式、图片或录音，也不上传孩子的想法。
- 发现、疑问和生活活动都不计入教材成绩、课程完成数、错题、复习周期或家长周报。卡片表示孩子留下了一段想法，不表示答案正确或已经掌握。
- 当前不跨设备同步。清除浏览器数据会清除卡片；关闭标签页可能失去草稿。设备朗读能力与手册保存分别工作。
