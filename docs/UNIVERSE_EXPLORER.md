# 宇宙与万物探索专题

## 目的与入口

入口：`/knowledge/universe`。

专题帮助小学生从熟悉的地球出发，认识事物之间的联系：我们在宇宙的什么地方，阳光怎样支持生命，水怎样在环境中流动，生命和普通物质又有哪些组成层次。

首批内容包括 **8 个观察视角、14 个事物节点、25 条关系、3 个互动小模拟**。内容是中文原创入门讲解，科学事实参考 NASA、ESA、USGS、NOAA、NIH 等一手资料。它是一组有选择的探索路线，尚未覆盖完整百科、科学教材或所有自然过程。

本文记录内容设计与实现范围。浏览器实测、自动检查和发布结果由 [VERIFICATION.md](VERIFICATION.md) 单独记录，本文不代表已经完成上线验收。

## 三种探索方式

1. **换个范围看看**：首次直接进入时从地球开始，带有有效位置地址时打开对应视角。选择一站，观察图示、阅读解释，再尝试回答一个问题。
2. **发现万物相连**：选择一个事物，查看与它有关的关系。用关系类型筛选，再逐条阅读箭头的具体含义。
3. **动手做小实验**：先作预测，再控制模型的步骤、时间或播放速度，观察结果并解释原因。

一次探索可以只完成一个问题，例如“太阳为什么能和兔子联系起来”。页面不把点击过、播放过或预测正确等同于长期掌握。

## 8 个观察视角

视角按宏观到微观排列，但页面首先打开地球。孩子可以向外认识更大的范围，也可以选取身边的事物观察其内部。

| 视角 | 主要发现 | 图示边界 |
| --- | --- | --- |
| 宇宙 | 地球和所有星系都在宇宙之中 | 画框不是宇宙边缘；可观测范围不等于整个宇宙的范围 |
| 银河系 | 太阳系属于银河系，太阳不在银河系中心 | 旋臂和太阳位置是结构示意 |
| 太阳系 | 太阳、八颗行星与其他天体有不同角色 | 行星按远近排开；真实天体不会总在一条直线上，大小和距离也未使用统一比例 |
| 地球 | 岩石、水、大气和生命共同构成身边环境 | 陆地轮廓和大气厚度经过简化 |
| 身边的生态系统 | 一片树林中的生物与环境相互影响 | 只选择一片树林作例子，生态系统没有统一大小 |
| 细胞 | 观察植物的一部分，认识生命的基本单位 | 展示一个植物细胞模型，不代表动物细胞或所有微生物的结构 |
| 分子 | 水分子由两个氢原子和一个氧原子结合而成 | 球和棒是结构符号，颜色、大小和连接方式的画法不是照片 |
| 原子 | 原子也有原子核和电子等内部结构 | 电子云表示找到电子的可能性；点不是多颗电子的照片，也没有固定行星轨道 |

每一站都是独立的示意图。视角之间跨越的尺度不相同，切换不表示连续、等比例地缩放。细胞路线是选取植物来认识生命；水、空气和岩石并不由细胞组成，也不需要“先变成细胞”才能认识它们的微观组成。

## 14 个节点与 25 条关系

节点按便于观察的主题分组：

- 太空：宇宙、银河系、太阳、地球、月球。
- 地球环境：水、空气、岩石与土壤。
- 生命：植物、动物、分解者、细胞。
- 微观物质：分子、原子。

这些分组方便浏览，不是互斥的科学分类。例如地球上的动物当然也属于宇宙。关系图中的位置只为方便阅读，不代表真实距离、大小、等级或时间先后。

### 五种关系分别回答什么

| 类型 | 含义 | 例子 |
| --- | --- | --- |
| 包含 | 空间归属或组成，具体含义由每条解释说明 | 银河系包含太阳；分子由原子组成 |
| 引力 | 天体之间相互吸引，影响运动轨道 | 太阳与地球；地球与月球 |
| 能量 | 能量从哪里传到哪里、怎样被利用 | 阳光支持光合作用；动物从食物中取得能量 |
| 物质 | 哪些物质进入生命活动或被分解 | 空气中的二氧化碳进入植物；枯叶交给分解者 |
| 循环 | 物质返回环境、再被利用的过程片段 | 分解将部分营养物质返回土壤；水蒸发和降水 |

箭头选取讲述方向，不代表引力只有单向作用。一条线只突出一种关系；同一对事物可能还有其他联系。筛选后没有连线，仅表示首批图谱没有展示相应关系。

### 三条可以讲给孩子听的路线

**找到地球的太空位置**：宇宙 → 包含银河系 → 银河系包含太阳 → 太阳通过引力影响地球轨道 → 地球通过引力影响月球轨道。前两步是包含，后两步是引力，月球不在地球内部。

**一片叶子怎样连接太阳和土壤**：太阳的光能 → 绿色植物制造有机物 → 吃植物的动物取得食物中的能量 → 分解者利用动物遗体等有机物中的能量。另一段联系是分解者把部分营养物质返回土壤 → 植物从土壤取得水和溶解的矿物质。返回土壤的是物质；能量在传递与利用中逐步以热散开，不沿这条路线重新循环。

**从叶子和水认识组成**：植物 → 细胞 → 分子 → 原子。也可以从水 → 水分子 → 原子出发。两条路线共享微观概念，但只有植物路线经过细胞。细胞含有许多种分子，一个细胞并不等于一个分子。

## 3 个互动小模拟

三个模拟都提供主动播放、暂停、回到起点和一道预测题。预测题反馈用于解释现象，可以修改选择后继续探索，不作为成绩或掌握度判断。页面不会自动开始播放；离开标签页、图像移出视野时会暂停。

| 模拟 | 可以做什么 | 重点理解 | 简化边界 |
| --- | --- | --- | --- |
| 看昼夜 | 拖动自转角度、每次转四分之一圈、连续播放，跟踪同一个地表观察点 | 地点转向太阳照亮的一侧或背向太阳，产生昼夜变化 | 从北极上空看赤道附近的点；忽略公转、地轴倾斜和纬度差异，以约 24 小时示意一次昼夜变化；不提供城市实时日出日落，也不用来解释四季 |
| 比公转 | 选择地球或火星，保持同一段经过时间；调整播放速度、向后看 30 天，跳到 365.25 天或 687 天 | 一边向前运动、一边持续受到引力，两个行星的公转周期不同 | 用匀速圆形轨道比较约 365.25 和 687 个地球日的周期；尺寸、距离和初始位置经过简化，不计算真实引力或真实天体位置；播放调速不等于给行星加速 |
| 追水滴 | 选择蒸发、凝结与成云、降水、汇流，逐步观察或连起来播放 | 太阳能量与重力参与水循环；云是小水滴或冰晶，水蒸气看不见 | 四步只展示一条可能路线；地下水、蒸腾、冰雪等路径没有完整展开，过程时长也不对应真实时间 |

这些模拟按预设教学规则呈现现象，没有求解真实天体运动、天气或生态过程。模型中的预测与反馈帮助孩子理解规则；对自然现象的科学验证仍需要观察、实验和证据。

## 需要保持的科学边界

- **宇宙与可观测宇宙**：我们能观察到的范围，不等于已知整个宇宙的边界。[NASA 宇宙术语](https://science.nasa.gov/universe/glossary/)、[ESA 儿童宇宙介绍](https://www.esa.int/kids/en/learn/Our_Universe/Story_of_the_Universe/The_Universe)。
- **植物的物质与能量来源**：以树木、青草等绿色植物为例，阳光提供能量，水和二氧化碳参与制造有机物，根还会吸收溶解的矿物质。不能把植物长大解释为只吃土。[美国能源部：植物利用空气中的二氧化碳生长](https://www.energy.gov/science/bes/articles/growth-and-repair-carbon-dioxide-air)。
- **能量流动与物质循环**：食物传递物质和能量，分解者让部分营养物质再次被利用；能量在利用过程中逐渐以热散开。[NOAA 食物网](https://www.noaa.gov/education/resource-collections/marine-life/aquatic-food-webs)、[NOAA 能量与物质](https://sos.noaa.gov/catalog/datasets/energy-planet/)。
- **水循环**：水可在空气、地表和地下等处转移，不是每一滴水都沿固定四步走完一圈。水蒸气与可见云滴也应区分。[USGS 地球水循环](https://www.usgs.gov/faqs/what-earths-water-cycle)。
- **细胞、分子和原子**：细胞是生命的基本单位；普通非生物物质也有微观组成。并非所有物质都由独立分子组成，原子也不是不可再研究内部结构的终点。[NIH 科学术语](https://nigms.nih.gov/education/glossary)、[美国化学会粒子模型教学](https://www.acs.org/education/resources/k-8/inquiryinaction/fifth-grade/chapter-1-investigating-matter-at-the-particle-level/matter-is-made-of-tiny-particles.html)。
- **元素来源**：氢和大部分氦在宇宙早期形成；碳、氧等许多元素与恒星及其演化有关。不能说所有元素都由恒星制造。[NASA 元素来源介绍](https://science.nasa.gov/universe/stars/neutron-stars/magnetars/where-does-gold-come-from-nasa-data-has-clues/)。

完整内容参考随 `lib/universe-content.ts` 中的 `universeSources` 提供，并展示在页面底部“给家长的内容参考”中。模拟采用的周期数据和模型参考记录在 `lib/universe-simulation.ts` 顶部。来源用于核对事实，不代表有关机构参与制作或认可本项目。

## 与现有学习系统的关系

专题独立于五科成长地图的 80 节课、160 道检查题，也独立于 `/knowledge/geometry` 空间小实验。地理成长地图仍用于逐课学习地球与环境，数学成长地图仍用于建立数、量和空间的概念。

专题接入首页的“星空观测站”。当前观察视角、关系节点或实验种类会写入地址，并作为世界探索的上次位置保存在当前浏览器；孩子也能收藏当前问题、继续“追着一滴水去旅行”等跨科路线。`#scale-earth`、`#relations-plant`、`#lab-water-cycle` 等有效地址可以直接恢复对应内容。全部位置与路线规则见 [KNOWLEDGE_WORLD.md](KNOWLEDGE_WORLD.md)。

世界位置记录独立于课程学习记录，不写入 Supabase。模拟时间、播放状态、预测选择、关系类型筛选及当前关系说明只用于当次交互，不会保存；重新进入实验从初始暂停状态开始。这里的到访、点击、播放和预测结果不计入五科课程完成数、教材练习成绩、错题本或家长周报。
