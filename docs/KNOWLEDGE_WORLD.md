# 我的知识世界

## 体验目标

首页从孩子所在的位置、看到的场景和产生的问题出发。孩子可以先做一个小动作、观察结果，再决定走向哪里；同一个问题可以连接不同学科。

当前采用二维场景地图、短互动和课程之间的连续引导。它提供可以选择和操作的探索环境，尚未包含三维自由行走、角色背包道具、实时聊天或自动生成课程。既有课程、教材练习和科学模型继续各自解释概念、记录证据。

本文描述当前实现和边界。测试、浏览器验收与发布结果见 [VERIFICATION.md](VERIFICATION.md)。

## 从进入网站到带着发现离开

1. 在 `/` 看到“我的世界，我来选路”，选择一个地点。
2. 在地点旁直接进行短活动，看清一个现象或找到一句话里的线索。
3. 可以把问题放进背包，继续进入对应课程；也可以换一个地点。
4. 课堂显示“我在什么地方”“本次在看什么”。通过看、做、解释、检查和联系继续学习。
5. 跟随小旅行时，课堂提供下一站的问题与连接说明；随时可以放下路线，自由探索。
6. 回到首页，可以继续上次位置，或打开背包回看收藏、已通过理解题的课程和需要再试的内容。

地图选择和短活动不会记录课程通过。世界里的“到访”只说明打开过相应内容；理解题仍根据实际作答记录。

## 六个地点

| 地点 | 地图上的短活动 | 继续探索的入口 |
| --- | --- | --- |
| 数字工坊 | 逐个点亮 5 只萤火虫，数过的不重复计数 | `/knowledge/math#count` |
| 故事森林 | 阅读一句话，从词语中找到速度的线索 | `/knowledge/chinese#chinese-listen` |
| 时光博物馆 | 将早上出发、中午野餐、傍晚回家按时间排列 | `/knowledge/history#history-before-after` |
| 大地山谷 | 在三行三列地图上逐格行走，用方向描述路径 | `/knowledge/geography#geography-relative` |
| 英语港湾 | 为见面情境选择英语问候 | `/knowledge/english#english-greetings` |
| 星空观测站 | 把地球转半圈，观察同一个地点的白天与黑夜 | `/knowledge/universe#scale-earth` |

短活动的选择与中间结果仅在当前场景保留，换地点后重新开始。它们用于观察和引出问题，没有单独的积分、掌握度或错题成绩。

地图地点使用可聚焦的原生按钮，可以通过 Tab 移动、Enter 或空格选择；在手机上选择地点后会定位到对应短活动。图示与教学模拟继续保留比例、时间或过程的简化说明。

## 三条跨科小旅行

### 出发，认识新朋友 · 4 站

| 站点 | 课程 | 为什么接着去这里 |
| --- | --- | --- |
| 找到自己的位置 | 地理：说位置，先说在谁旁边 | 约定参照物，让朋友找到自己 |
| 听清朋友的任务 | 语文：听清一句话里的小任务 | 理解谁要做什么，一起准备出发 |
| 用英语问好 | 英语：见面与告别，先说一句 | 根据相遇的情境选择问候 |
| 清点带来的物品 | 数学：一个一个，数清有多少 | 一边指一边数，让一次小合作做完整 |

这条路线使用四科学习路径的首课，适合从基础开始。

### 追着一滴水去旅行 · 4 站

地球视角 → 水循环小实验 → 地理“顺着水流，连接上游和下游” → 语文“把观察到的样子说具体”。

先认识水所处的环境，再操作一条可能的水循环路线，接着观察河流与地势的联系，最后练习向别人描述观察。后两站沿用原课的基础提示；遇到新概念，可以回到前置课程，并不要求孩子一口气完成全部站点。

### 给未来留一条线索 · 3 站

历史“先发生什么，后发生什么” → 历史“旧物也会留下线索” → 语文“答案要在文字里找依据”。

从时间顺序出发，观察物品能留下哪些证据，再练习从文字中寻找支持理解的线索。路线没有替代历史和语文各自的完整基础路径。

三条路线共有 11 个站点，可以按顺序走，也可以打开任一站。显示“已到访几站”只依据实际打开过的位置；路线没有通过分数，也不会因为走到最后一站就宣称掌握。

## 路径与恢复

| 地址 | 用途 |
| --- | --- |
| `/` | 世界地图、六个短场景、小旅行与背包 |
| `/#place-math` 等 | 选中指定地点 |
| `/#backpack` | 打开探索背包 |
| `/knowledge` | 保留五科知识路线册及旧数学课程链接兼容 |
| `/knowledge/{subject}#{lessonId}` | 打开一门学科中的指定课程，恢复原学习步骤 |
| `/knowledge/universe#scale-earth` | 指定观察视角 |
| `/knowledge/universe#relations-plant` | 指定关系图节点 |
| `/knowledge/universe#lab-water-cycle` | 指定实验种类 |
| `/knowledge/geometry` | 保留空间小实验及独立进度 |
| `/practice` | 原学习工作台，现为练习营地 |
| `/practice#mistakes` | 教材错题 |
| `/practice#review` | 学习复盘 |
| `/practice#parent` | 家长账户入口；真实账户暂未开放 |
| `/practice#settings` | 教材与课程设置 |

路线链接把有效的 `trail` 和 `stop` 放在查询参数中，例如：

```text
/knowledge/universe?trail=water-trip&stop=cycle#lab-water-cycle
```

只有目录中已声明的路线、站点与当前内容匹配时，链接才会恢复路线。世界首页的“接着刚才的探索”会恢复最近课程、视角、关系节点或实验种类；课程内部步骤仍由原学科进度恢复。模拟时间、播放状态、关系筛选和预测选择不保存。

路线另存最近到达的本站位置。比如走到“河流”时返回“相对位置”补基础，首页继续探索会打开基础课，而“接着走这条路线”会回到河流，不会因为已经到访过河流就跳过它。重新选择同一条路线保留该位置，改选其他路线或放下路线时清空；只有实际进入当前路线的站点才更新。

首页选中一个地点只更新地图选择，不把该地区首课记作已经到访。浏览器实际进入课堂或宇宙视角后，课堂中的旅程组件才记录当前位置。

## 背包与数据边界

世界记录使用独立的浏览器键 `gogostudy:world:v1`，只保存以下信息：

- 选中的地图地点。
- 上次打开的内容位置。
- 当前选择的小旅行。
- 这条小旅行最近到达的站点，便于从基础课返回原站。
- 到访过的有效内容位置。
- 收藏的问题 ID。

目录有 105 个可恢复位置：80 节五科课程、8 个宇宙视角、14 个关系图节点、3 种实验。122 个可收藏问题分别对应 6 个地点、11 个路线站点和这 105 个内容位置。同一内容在不同旅行中可以带着不同的问题观察。

背包读取五科既有存储中的有效检查题 ID，只有本课两道检查题都通过时，才列入“我试着用过的知识”。它忽略保存对象中直接声称完成的标记，并将未通过、需要再试的课程单独列出。背包不写回学科记录，也不把世界短活动加入教材练习、错题本、间隔复习或家长周报。

这些记录保存在当前浏览器，不要求账号，不写 Supabase，不会自动同步到其他设备。世界记录通过浏览器存储事件同步同源标签页，同页旅程组件也会及时保持一致。存储不可用时，当前客户端会话有内存备用记录；整页重载、关闭页面或浏览器后可能丢失。页面会显示保存提示。

正式练习的数据模型和判题规则保留在练习营地：服务端判分、课程包隔离、提示后的辅助完成、错题订正和 1 / 3 / 7 天间隔复习均沿用原逻辑。迁移入口不重算旧记录。

## 实现与维护

- `app/page.tsx`、`components/world/world-home.tsx`：世界首页和背包。
- `components/world/world-map.tsx`：可选择的二维地图。
- `components/world/world-discovery.tsx`：六个短活动。
- `components/world/journey-companion.tsx`：课堂位置、当前问题、路线和下一站。
- `lib/world-content.ts`：地点、路线、有效目的地、问题及内部链接生成。
- `lib/world-lesson-index.ts`：仅包含标题、目标和检查题 ID 的轻量课程索引，避免把五科完整内容带入首页。
- `lib/world-progress.ts`：状态校验、到访与收藏变更、原学科证据读取。
- `lib/use-world-progress.ts`：浏览器保存、同页及跨标签页同步、存储失败备用记录。
- `app/practice/page.tsx`、`components/study/study-dashboard.tsx`：保留原学习工作台。
- `lib/practice-navigation.ts`：练习营地各入口的地址映射。

自动测试检查轻量索引与原 80 课一致、路线终点有效、内部地址安全、位置与收藏恢复、到访与理解证据分离、损坏记录恢复和练习入口映射。增加课程或问题时，同时更新目录并运行完整测试；浏览器中的触控、键盘、前后导航和续程行为仍需单独验收。
