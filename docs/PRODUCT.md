# GoGo 学堂：产品范围与后续方案

## 当前产品定位

GoGo 学堂先服务浙江省使用人教版数学二年级上册的家庭。孩子看到短任务、清楚反馈和鼓励性提示；家长看到错题、复习节奏和最近 7 天的学习情况。当前生产环境以无需登录的浏览器体验模式运行。

默认 `2025课程包` 是依据公开知识框架制作的原创练习包，不是出版社官方题库，也不宣称逐页同步教材。它包含 56 道题、6 个单元、14 个技能和 24 道程序绘制的视觉题。原有 29 道题保留为 `旧版课程包`，两套课程包的练习、错题、复习和统计完全隔离。

## 已实现的学习闭环

1. 首页同时展示今日练习、待订正、到期复习三张任务卡。订正与复习分别最多取 5 题，旧任务优先，任何一类都不会因为另一类存在而被隐藏。
2. 每题可以直接作答或查看提示。答案由服务端判定，公开题库接口不会返回标准答案、解析或提示；提示通过私有接口获取，并在云端按用户与本次答题 ID 记录短期会话。
3. 错题自动进入待订正，并可记录计算、读题、口诀、分类标准、单位测量或方法不熟等原因。
4. 答题使用 `support_level` 区分独立完成、提示辅助和引导完成。看过提示或重试后答对，仍会留在错题本等待下一次独立订正，不计入独立正确率，也不会开始或推进间隔复习。
5. 只有独立订正正确才会进入 1 / 3 / 7 天复习；只有在到期日独立答对才推进下一阶段。复习再次出错会回到待订正，完成三次才标记已掌握。
6. 家长复盘按最近 7 个中国日历日统计学习天数、练习数、独立正确率、正确订正、完成复习和最常见错因。技能建议至少需要 3 次独立练习并覆盖 2 道不同题，数据不足时不下结论。
7. 学习小记、最近记录、复习安排和知识技能统计与当前课程包绑定，不跨版本汇总。

## 课程内容范围

`2025课程包` 覆盖：

1. 分类与整理
2. 1～6 的表内乘法
3. 1～6 的表内除法
4. 厘米和米
5. 7～9 的表内乘除法
6. 复习与关联

14 个技能各有 4 道原创题，难度分布为 28 道基础、20 道应用、8 道推理。视觉题使用数据驱动的圆点分组、分类卡片和刻度尺，不使用教材截图、插画或版面。详细映射、资料依据与人工审校要求见 `docs/CURRICULUM.md`。

旧版课程包保留 100 以内加减法、表内乘法、长度、角、观察物体、时间和搭配等 29 道历史题。没有 `revision` 的旧设置和历史记录会明确映射到旧版，避免新版上线后改变原有统计含义。

## 当前边界

- 数学先行；语文和其他省份、教材、年级、册次组合显示准备中，不会借用当前题库。
- 每个家长账号对应一个学习空间，尚无多孩子档案、教师端、排行榜或班级管理。
- 体验记录只保存在当前浏览器，清除浏览器数据会清除记录；未来登录后的云端数据与体验数据不会隐式合并。
- Supabase 项目尚未创建和连接。邮箱验证码界面、接入代码和迁移脚本已经准备，但登录、注册、云端保存和多设备同步没有正式上线。
- 云端答题历史读取上限为 50,000 条；当前和旧版课程包各读取最新 100 条学习小记。课程包继续扩展或数据规模增大后需要分页或服务端聚合。
- 可信写入代码与权限收紧迁移已经完成，但尚未在真实 Supabase 项目验证。开放账户前仍需确认浏览器直接写入被拒绝、服务端 API 写入成功，并检查 Security 与 Performance Advisors。
- 题库是可用的首个内容版本，不等同于完整课时、所有题型或纸质教材配套资源。涉及具体印次、页码或“完全同步”的表述仍需以实物教材版权页和目录复核。

## 接下来优先级

### P0：完成可信账户与云端数据链路

创建 Supabase 新加坡项目并依次应用四份迁移；配置邮箱验证码模板、正式 SMTP、生产 URL 和环境变量。可信服务端写入、提示辅助程度派生、原子答题函数和撤销 `authenticated` 直接写权限的代码已经完成；接下来验证双账号隔离、匿名与直接写入拒绝、API 写入、并发与重复提交、多设备、过期验证码和断网恢复，验收通过后再对外开放登录注册。

### P1：扩充课程内容与复习质量

继续为每个技能增加不同数字和不同情境的变式题，补充综合实践任务。内容更新使用稳定题目 ID、`contentVersion` 和审校状态；改变数学含义或答案时新建 ID，保留历史快照。复习可以逐步从原题回忆升级为同技能变式，但仍保持儿童可理解的短任务。

### P2：完善家长使用

增加孩子档案、主动选择的体验记录导入、可下载周报和更长期趋势。统计以解释学习过程为主，不做孩子排名、焦虑倒计时或一次答题能力定论。

### P3：扩展语文与其他课程

沿用课程包、学习记录和复盘框架，题型扩展到拼音选择、识字词语、句子排序和阅读理解。客观题可以自动批改；开放题先提供家长反馈流程，不能用简单字符串匹配代替理解判断。

## 技术与体验约定

- 公开缓存只包含不带答案的题库；用户状态、登录信息、判题结果和写请求始终 `private, no-store`。
- 题库按课程包加载，并在当前页面会话复用；单元筛选在浏览器完成，避免重复下载完整课程包。
- 未配置 Supabase 时直接恢复浏览器记录，Supabase SDK 按需加载。
- 页面以手机优先，覆盖手机、平板和桌面；关键操作保持足够触控面积，内容卡片在窄屏不产生横向滚动。
- 学习日、连续天数、到期复习和 7 天周报统一使用 `Asia/Shanghai` 日历边界。
- Vercel Functions 使用新加坡区域以缩短中国方向的跨洲路径。面向中国大陆正式商用前仍需进行多运营商、不同城市和弱网实测，并评估备案、境内部署或 CDN、邮件/短信送达和隐私合规。
- 前端只能使用 Supabase publishable key。任何服务端 secret 必须留在服务端环境，不能进入 `NEXT_PUBLIC_*`、浏览器构建或 Git 仓库。
