## 原创与非官方同步边界

1. 本包只依据课程目标、数学事实和公开的单元结构设计内容，没有录入、扫描、描摹或改写教材题目。
2. 题干、数字组合、人物称呼、提示、解析、干扰项和示意图均为本项目原创；图形仅使用程序绘制的圆点分组、分类卡片和刻度尺。
3. 不使用教材页码、题号、版面、角色、插画、照片、故事线或配套资源文件。
4. “人教版”用于说明知识框架适配范围，不表示人民教育出版社参与、授权、审定或推荐本网站。
5. 不使用“教材原题”“官方题库”“逐页同步”等描述。需要精确匹配某一印次时，应新增内容版本并保留来源复核记录。
6. 已产生学习记录后，不原地改变题目的数学含义或正确答案；这类修改必须创建新题目 ID。`contentVersion` 只用于不改变判分结果的内容包升级，历史记录继续保留题目快照。

## 人工审校清单

每次发布新内容版本，应由审校者逐题确认以下事项：

### 课程范围

- 单元和技能与本课程包的映射一致，没有混入旧版的角、观察物体、认识时间、100 以内加减法或搭配内容。
- 乘法、除法、长度和分类的深度适合二年级上册；综合题只调用学生已经学过的关系。
- 口诀题覆盖 2～6 与 7～9 的代表性乘除关系，不把有限题量描述成完整口算题库。

### 数学与判分

- 题意只有一个合理答案；选择题正确答案在选项中只出现一次，选项之间不等价。
- 分类标准清楚，同一标准下每个对象归属明确；题目若更换标准，会明确告诉孩子。
- 平均分与“每几个一组”表述清楚，答案单位与所求对象一致；本版本不引入有余数除法。
- 长度单位和生活中的数量级合理；刻度尺题使用终点刻度减起点刻度，不依赖屏幕上的实际物理尺寸。
- 服务端保存标准答案和解析，公开题目接口不得提前返回答案。

### 儿童语言与反馈

- 题干以短句为主，避免不必要的生词、否定套否定和竞赛式陷阱。
- 数字、单位和条件完整；两步题的关系明确，不要求无关的课外常识。
- 提示只指出观察方向或方法，不直接给出答案；解析说明关键一步，并使用儿童能理解的表达。
- 干扰项来自真实易错方式，例如混淆份数和每份数、忘记非零刻度起点或选错长度单位。
- 反馈不使用“笨”“落后”等负面标签，不把一次答题结果描述为能力定论。

### 视觉、原创与可访问性

- 分类图、圆点分组和刻度尺与题干数据一致，文字替代信息足以完成同一道题。
- 不使用来源不明的图片、教材截图或与教材插图近似的角色造型。
- 在手机、平板和桌面上检查图形没有裁切，放大文字后仍能读取标签和刻度。
- 逐题记录审校结果；存在歧义、超纲、版权来源不清或视觉不可读时，保持 `draft`，不得进入生产题库。
