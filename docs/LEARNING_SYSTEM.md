# 五科知识成长地图：从基础概念到综合运用

知识成长地图的总入口是 `/knowledge`，包含数学、语文、历史、地理和英语。它先帮助孩子理解一个个基本概念，再显示概念之间的联系，让新知识建立在已经认识的东西上。这里的“从点到面”指从小概念逐步形成知识体系，空间中的点、线、面、体是其中一个专题。

首批内容共 **80 节完整课程、160 道理解与迁移题**。每科有 6 个认知阶段、4 个知识领域；数学 32 课，其余四科各 12 课。每一课都有生活情境、互动、解释、两道检查题和知识联系，可以实际学习。

这是原创核心概念路径，不是小学知识全集，也不是某版教材的逐课复刻。阶段表示本产品的认知顺序，不直接对应年级或学期。历史、地理按孩子能理解的情境提供启蒙学习，不宣称与小学独立学科课表同步。

## 五科入口与路线

| 学科 | 入口 | 六个成长阶段 |

## 数学六阶段的具体内容

| 阶段 | 课程数 | 核心概念 |
| --- | ---: | --- |
| 1. 发现数量和形状 | 5 | 点数、一一对应、数量比较、零、基本图形 |
| 2. 学会表示与比较 | 5 | 数的分合、十个一、数的顺序、统一测量单位、重复规律 |
| 3. 理解加减与单位 | 6 | 加法、减法、加减互逆、数位、理解问题、厘米和米 |
| 4. 认识分组和关系 | 6 | 相同组与乘法、平均分与除法、倍、时间、周长、分类统计 |
| 5. 认识部分与空间 | 5 | 分数、等值分数、小数、面积、体积 |
| 6. 综合应用与推理 | 5 | 多步问题、比、百分数、可能性、综合方案 |

每课都有一个明确目标，例如“每个物品只数一次”“先确定整体再认识几分之几”。内容从实物与情境进入，先解释含义，再引入符号和计算。

### 数学的四个领域

| 领域 | 孩子要逐步认识的关系 |
| --- | --- |
| 数与运算 | 数量、部分与整体、数量变化、相等的组以及数的不同表示 |
| 图形与测量 | 形状、相同单位、长度、时间、边界、面的大小与空间大小 |
| 数据与规律 | 重复单元、分类计数、图表证据，以及随机结果的可能性 |
| 解决问题 | 区分已知和所求，选择方法，分步计算，解释并检查方案 |

领域可以筛选查看，但学习依赖会跨越领域。例如，数数支持统一单位的测量，等量分组支持长方形面积计算，分数和面积又共同支持花圃规划。筛选不会改变课程本身的基础要求。

## 知识怎样连起来

每节课声明本学科的前置课程，构成没有循环的依赖图。课程数组按前置在前、后续在后的顺序组织。课堂同时展示“它用到了哪些基础”“以后会用它做什么”，以及说明前后联系的“为什么学它”。同一学科的依赖可以跨领域；当前推荐不强制跨学科依赖，也不会要求先通过数学某课才能预览地理课。

典型联系包括：

- 数清数量 → 一一配对 → 比较多少 → 认识零 → 数的分合 → 加减意义。
- 加法与重复分组 → 乘法 → 平均分与除法 → 分数 → 小数、等值分数与百分数。
- 数数与统一单位 → 标准长度 → 周长；乘法与单位方格 → 面积 → 按层计数的体积。
- 理解问题 → 多步计算；结合面积、数据与占比，解释综合方案。
- 语文从听清信息、辨认字词，连接阅读证据与有条理的表达。
- 历史先学时间与材料来源，再结合生活、技术和交流，形成有依据的解释。
- 地理从位置与地图走向地形水流、天气气候，最后综合考虑人与环境的联系。
- 英语从情境和完整词句出发，连接颜色数量、对应问答，再读短文、作介绍。

推荐逻辑会检查一课的直接和间接前置：

1. 优先推荐基础已经具备、仍需纠错的课程。
2. 再按课程顺序推荐基础已经具备、尚未完成的课程。
3. 尚未完成基础的课程也允许预览，同时指出缺少的基础并提供返回入口。

孩子可以自己选择课程，系统用提示引导补齐基础，不用锁定课程阻止探索。推荐依据是本地学习记录，不是对孩子实际能力的完整诊断。

## 每课五步

| 步骤 | 页面内容 | 教学目的 |
| --- | --- | --- |
| 看一看 | 生活小故事与本课目标 | 知道要弄明白什么 |
| 动手试 | 可以操作的小教具 | 通过点、分、移、量、铺等操作观察变化 |
| 想明白 | 分步解释与一句关键发现 | 把刚才的操作联系到概念，用自己的话说清楚 |
| 用一用 | 一道理解题、一道迁移题 | 检查含义，并换一个情境试用 |
| 连起来 | 前置概念、当前发现和后续用途 | 把这一课放回知识体系，并决定下一步 |

步骤可以来回查看。页面会保存每课停留的步骤，但不会因为看过页面、操作过教具或进入最后一步就自动标记完成。

数学保留 16 种教具：点数、比较、分合、加法、减法、分组、平均分、测量、分数、规律、数据、图形、面积、体积、小数和比。它们按本课参数呈现具体情境，例如周长按边累计、百分数把四等份细分成百等份。

通用课堂另有 6 种互动形式：

| 形式 | 适用例子 |
| --- | --- |
| 排序 | 按经过组织句子，排列时间或制作步骤 |
| 配对 | 把词语与意思、史料与研究用途联系起来 |
| 分类 | 分清观察与联想、天气与气候、不同交流目的 |
| 找证据 | 判断线索是否支持结论，识别没有依据的猜想 |
| 地图走格子 | 根据起点、方向和目标练习说明路线 |
| 可选听读 | 对照完整词句与意思，使用设备语音辅助听读 |

听读依赖浏览器和设备可用的语音，并非录制教材音频。无法播放时仍可阅读文字和解释，也可以由家人示范；页面不录音、不自动评判发音，更不把字母名称的朗读当作可靠的词内音素示范。语文和英语检查题验证的是内容理解，不能替代口语、书写或阅读能力的全面评估。

## 两道题与复盘

每课有两道选择题：第一道检查理解，第二道换情境迁移。五科共 160 题，数学 64 题，其余各 24 题。答案位置经过打散。答题后显示原因；答错时可以重新作答，也可以先返回教具再试。

- 两道题均有通过记录，才显示“本课已完成”。
- 答错的课程进入“再想一想”和“留给下一次的小问题”。
- 已完成课程重新作答出错，会撤回该题的通过记录，并重新进入纠错。
- 其他仍然正确的题目记录保留；再次通过缺少的小题后，该课恢复完成状态。
- 完成状态由题目通过记录推导，不直接相信浏览器中保存的完成标记。

“本课完成”只表示通过了本课的理解练习。重试、看过解释后答对同样会记录通过，因此它不能代表独立正确率、长期掌握程度或学校成绩。第五步鼓励孩子换一个身边的例子讲给家人听，并在以后继续运用。

成长地图当前使用待纠错课程列表进行复盘，没有独立的按日到期复习计划。教材练习已有的 1 / 3 / 7 天间隔复习仍按原规则运行，两者不混算。

## 与已有内容的关系

| 内容 | 入口 | 作用与记录范围 |
| --- | --- | --- |
| 五科成长地图 | `/knowledge` 及各科学习页 | 80 个核心概念组成的引导路径，每科独立记录步骤、双题检查和纠错 |
| 空间小实验 | `/knowledge/geometry` | 原有点、线、面、体专题，12 个空间知识点、7 种互动实验，保留独立探索进度 |
| 教材练习 | 学习首页 | 按省份、教材、年级、学期、科目和课程包组织的练习，使用服务端判分、原有错题本、间隔复习和家长周报 |

空间专题用于进一步观察几何概念。成长地图与空间专题的小题将答案和解释一同提供给浏览器，目的是学习引导；教材练习保持公开题包与服务端答案分离。

成长地图暂未把概念映射为各教材课程包的正式成绩，也不向原有错题本、家长周报或 Supabase 写入图谱学习记录。增加语文、历史、地理、英语成长课程，不代表这些科目的教材练习题库已经同步开放。

## 浏览器进度与兼容

五科分别使用 `gogostudy:<subject>-learning:v1`，其中 `subject` 是 `math`、`chinese`、`history`、`geography` 或 `english`。记录包括当前课程、每课步骤、通过的检查题和待纠错课程。不同学科的课程 ID、题目 ID 和保存记录相互隔离。

数学继续使用原来的 `gogostudy:math-learning:v1` 和课程 ID，不要求重新学习已完成的课。旧 `/knowledge#count` 等有效数学节点链接，会兼容定位到 `/knowledge/math#count`。空间专题继续使用 `gogostudy:geometry:v1`，不会误算为数学主线或其他科目的完成记录。

- 正常情况下刷新页面可以恢复，且能接收同一浏览器其他标签页的进度更新。
- 打开课程链接可以定位到指定概念；切换学科或课程不会清空其他学科与课程的记录。
- 损坏的记录、不认识的课程或题目 ID 会在解析时丢弃或恢复为初始状态。
- 暂无账号云端保存、跨设备同步或多个孩子的独立图谱档案。同一浏览器配置中的使用者共享这份记录。
- 清除网站数据会清除进度；无痕窗口通常不会长期保留记录。
- 浏览器禁止或无法写入存储时，页面仍可学习并显示提示，但关闭后进度可能丢失。

## 页面加载与性能

`/knowledge` 总览只向浏览器传入学科和阶段信息，以及课程标题、前置关系、检查题 ID 等摘要，用来恢复各科进度和展示继续学习。总览不向浏览器发送五科完整故事、活动、答案与讲解。

五个学科详情通过 `/knowledge/[subject]` 静态生成；服务端选择相应课程，只将当前学科的完整内容传给课堂。新增学科共用进度和课堂结构，避免把整套内容一次性加入总览页面。此处描述的是加载设计，具体构建与浏览器验收结果记录在 `docs/VERIFICATION.md`。

## 内容准确性与组织参考

课程和生活例子为本项目原创。组织参考包括教育部发布的 [《义务教育课程方案和课程标准（2022 年版）》通知及附件](https://hudong.moe.gov.cn/srcsite/A26/s8001/202204/t20220420_619921.html)。本产品的阶段、领域名称和具体课程依赖是教学设计，不是官方指定的唯一学习路径。

新增四科的 `sources` 保存直接来源链接。语言类参考教育部关于 [汉语拼音辅助学习的说明](https://www.moe.gov.cn/jyb_xxgk/xxgk_jyta/jyta_yys/201610/t20161018_285368.html)及 [British Council 字母学习资源](https://www.teachingenglish.org.uk/teaching-resources/teaching-primary/lesson-plans/level-1/alphabet)。历史结合博物馆和联合国教科文组织资料，例如 [良渚古城](https://whc.unesco.org/en/list/1592)与 [大运河](https://whc.unesco.org/en/list/1443)；地理结合 [NASA 地球资料](https://science.nasa.gov/earth/facts/)和 [USGS 河流资料](https://www.usgs.gov/water-science-school/science/rivers-streams-and-creeks)。具体参考范围以各科文件为准。

编写与审查时保留以下边界：

- 分数先确定整体，并强调平均分；整体不同，相同分数对应的实际量可能不同。
- 比区分两个量的关系和部分占整体的比例；百分数表示占比，不是固定个数。
- 统计结论限定在本次调查范围；随机实验明确同等机会的条件，不把“更可能”说成“一定”。
- 周长、面积和体积分别描述边界长度、面的大小和空间大小，不混用单位。
- 屏幕尺子用于说明测量过程，不代表屏幕上的实际厘米长度。
- 语文中拼音帮助记录字音，意思仍需联系字词；例子不推广成所有音节的规则；观察、联想和原文依据分清。
- 英语字母名不等于所有词内发音；本课规则名词加 s 的例子不代表所有复数变化；物品特征、个人喜好和文本证据分清。
- 历史中先后不等于因果，传说或复原图不自动成为原始证据；讲蔡伦改进造纸，不把技术变化说成从无出现；丝路是交流网络。
- 地理图中北向有明确约定，示意格子不代表真实距离；上游下游依水流判断；一天的天气不能代表长期气候；表面海陆比例不等于地球内部体积比例。
